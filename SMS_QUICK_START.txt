📋 OPTION 1: TWILIO (RECOMMENDED FOR HACKATHON)

  1. Sign up: https://www.twilio.com/try-twilio
     → Get $15 free credit (500+ SMS)
  
  2. Get credentials:
     → Console Dashboard: https://console.twilio.com
     → Copy: Account SID, Auth Token
     → Buy a Phone Number (free with trial)
  
  3. Configure:
     cd backend
     notepad .env
     
     Add:
     TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxx
     TWILIO_AUTH_TOKEN=your_token_here
     TWILIO_PHONE_NUMBER=+1234567890
  
  4. Install:
     venv\Scripts\activate
     pip install twilio
  
  5. Test:
     python test_sms.py
  
  ✅ DONE! SMS will now be sent to real phones!

═════════════════════════════════════════════════════════════════════

📋 OPTION 2: MSG91 (CHEAPEST FOR INDIA)

  1. Sign up: https://msg91.com/signup
     → Get 100 free SMS
  
  2. Get Auth Key:
     → Dashboard → API → Auth Key
  
  3. Create Template:
     → Campaigns → Create Template
     → Text: "Your RuralAI OTP is ##OTP##. Valid for 5 minutes."
     → Wait 24-48 hours for DLT approval
  
  4. Configure:
     cd backend
     notepad .env
     
     Add:
     MSG91_AUTH_KEY=your_auth_key
     MSG91_TEMPLATE_ID=your_template_id
  
  5. Test:
     venv\Scripts\activate
     python test_sms.py

🚨 TROUBLESHOOTING

  Problem: SMS not received
  → Check .env file has correct credentials
  → Run: python test_sms.py
  → Check backend logs for delivery status
  
  Problem: Still in demo mode
  → Verify provider credentials in .env
  → Restart backend: python app.py
  → Clear browser cache
  
  Problem: Invalid credentials
  → Double-check Account SID/Auth Token
  → Ensure no extra spaces in .env
